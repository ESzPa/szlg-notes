# Karbonsavak
- **Karboxilcsoport**: karbonilcsoport+hidroxilcsoport
- **Funkciós csoport szerkezete**: poláris, vizes oldat savas
## Elnevezés
- Alapszénhidrogén neve + sav
- Szénhidrogén szénatomszámába a karboxilcsoport szénatomját is bele kell számolni
- Számozást számozását karboxilcsoport szénatomszámával kezdjük
- **Metánsav**: hangyasav
- **Butánsav**: vajsav *lábszag*
- **Pentánsav**: valeriánsav
- **Etándisav**: sóskasav
