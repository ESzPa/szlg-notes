# Karbonsavak
## Kémiai tulajdonság
1. Savak: $H^+$ leadására képes
	- $CH_3-COOH$ + $H_2O$ $\longrightleftharpoons$  $CH_3-COO^-$ + $H_3O^+$ 
	- $CH_3$ + $NaHCO_3$ $\longrightarrow$ $CH_3COO^+$ + $Na^+$ + $H_2CO_3$ 
2. Sav+fém $\longrightarrow$ fém-só + $\text{H}_\text{2}$ 
	- $2CH_3COOH$ + $Zn$ $\longrightarrow$ $Zn^{2+}$ + $2CH_3-COO^-$ + $H_2 \uparrow$
